# EFMW Lagrangian Audit

**Frozen candidate C1 · Full 165-triplet comparison · Lean 4.28.0**

This project derives and audits a proposed effective Lagrangian for the 11-sector EFMW FieldSpace catalogue. It preserves the original sources, records every change of convention, and compares all **585 displayed statements** against the candidate's actual variations.

**Result:** all **360 scalar interaction magnitudes** match independently differentiated candidate potentials under explicit reciprocity and curvature identifications. The source equations' potential signs differ under the frozen (-+++) convention. The original gauge currents and gravitational placeholders do not establish complete equivalence.

The included verification record distinguishes successful finite Lean proofs from unproved continuum and physical claims. Open **[index.html](index.html)** for an offline searchable dashboard.

No historical source has been silently repaired. A matching corrected scalar polynomial is not evidence that every original equation was already correct. Generic cubic interactions can also make the potential unbounded below.

## Reproduce

Install Lean through [elan](https://github.com/leanprover/elan) and Python **3.10 or newer**. This project has no third-party Python dependencies and no external Lean packages.

```sh
python3 scripts/verify.py --clean
python3 scripts/render_dashboard.py
```

The verifier checks frozen definitions and source hashes, regenerates every audit row and certificate, runs the Python regression suite, builds the Lean library, audits transitive axioms, rechecks compiled proofs with `leanchecker`, and verifies deliberate failures.

For individual steps:

```sh
python3 scripts/audit.py
python3 -m unittest discover -s tests -v
lake build
lake env lean Audit.lean
lake env leanchecker -v EFMWLagrangian
python3 scripts/check_axiom_guard.py
```

The original authoring environment required an explicit-path launcher for Lean's executable autodetection. It used the unmodified upstream frontend and kernel libraries. The included build status discloses that route; normal GitHub Actions uses the standard launcher. See [reproducibility](docs/REPRODUCIBILITY.md).

## Formal scope

There are **720 explicit scalar certificates**: one derivative-magnitude identity and one original-sign nonidentity for each scalar statement. Core.lean supplies additional narrow support theorems. Counts in the axiom log include compiler-generated equation lemmas and should not be interpreted as independent physical theorems.

Lean checks finite formal polynomials. The source parser, continuum variational calculus, general stability and physical interpretation are not fully formalized. The package does not prove the original 585 equations, a new force, or physical EFMW as a theory of nature.

## GitHub use

Create a repository such as `EFMW-Lagrangian-Audit` and upload this directory's contents. The included `.github/workflows/verify.yml` will run the build and audit. To serve the dashboard, enable GitHub Pages from the main branch's root. The dashboard has no external assets and also opens locally.
